Computer Graphics Paint

A basic MS Paint-like computer graphics project made with C++ Win32 GDI. It demonstrates raster drawing, colors, geometric shapes, text, history, and bitmap saving.

Drawing tools

Use Pencil for freehand strokes, Line for straight lines, Rectangle and Ellipse for geometric shapes, Text for labels, and Eraser for corrections.

Color selection

The toolbar includes twelve preset colors. Brush size can be changed from 1 to 50 pixels.

Undo and redo

The program keeps up to thirty drawing states, making experimentation safe and simple.

Save functionality

Save the canvas as a standard .bmp bitmap image using the Save BMP button.

Build and run

Open Developer Command Prompt for Visual Studio in this folder and run:

cl /EHsc /DUNICODE /D_UNICODE main.cpp user32.lib gdi32.lib comdlg32.lib /link /SUBSYSTEM:WINDOWS

Then launch main.exe. MinGW users can use:

g++ -std=c++17 -municode -mwindows main.cpp -o paint.exe -luser32 -lgdi32 -lcomdlg32

CGR concepts demonstrated

The application uses the Win32 GDI raster pipeline: device contexts, pens, brushes, bitmaps, pixel-compatible memory surfaces, line rasterization, ellipse and rectangle primitives, and bitmap file output. These are the core concepts normally studied in Computer Graphics.
